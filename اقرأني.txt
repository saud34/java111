منصّة «أساسيات برمجة الحاسب بلغة جافا» — النسخة المفصولة (المحتوى في ملفات JSON)
================================================================================

المحتويات:
- index.html            : التطبيق (التصميم + المنطق + مُشغّل جافا المدمج). لا تحتاج لتعديله.
- data/lessons.json     : محتوى الدروس (تعدّله بنفسك).
- data/quizzes.json     : أوراق العمل وإجاباتها (تعدّله بنفسك).
- manifest.json, sw.js, icon-192.png, icon-512.png : ملفات PWA (تثبيت كتطبيق عند الاستضافة).

مهم: هذه النسخة تقرأ المحتوى من ملفات JSON، ولذلك يجب تشغيلها عبر «خادم»
(الفتح المباشر بالنقر المزدوج لن يحمّل المحتوى بسبب قيود المتصفّح).

تشغيل محلي بسيط (اختر واحدًا):
  • بايثون:   افتح موجّه الأوامر داخل هذا المجلد ثم:   python -m http.server 8000
              وافتح المتصفّح على:   http://localhost:8000
  • VS Code:  إضافة «Live Server» ثم Open with Live Server.

النشر المجاني (يُفعّل PWA تلقائيًّا): ارفع المجلد كاملًا إلى GitHub Pages أو Netlify.

------------------------------------------------------------
كيف تعدّل الدروس؟  (data/lessons.json)
------------------------------------------------------------
الملف كائن، مفتاحه رقم الدرس، وقيمته { "title", "subtitle", "blocks" }.
"blocks" مصفوفة عناصر، كل عنصر نوعه "t":
  {"t":"h","n":"١","txt":"عنوان القسم"}          ← عنوان
  {"t":"p","txt":"فقرة نصّية."}                    ← فقرة
  {"t":"ul","items":["نقطة","نقطة"]}               ← قائمة
  {"t":"note","kind":"teal","lb":"تنبيه","txt":"..."}  ← صندوق ملوّن (teal/amber/green/red)
  {"t":"banner","a":"عبارة عربية","e":"English"}   ← شعار مميّز
  {"t":"pre","code":"مقطع كود للعرض فقط"}          ← كود ثابت (لا يُشغَّل)
  {"t":"code","code":"برنامج كامل"}               ← مثال قابل للتشغيل (زر «تشغيل»)
  {"t":"out","txt":"الناتج المتوقّع"}              ← صندوق ناتج (أخضر)
  {"t":"table","head":["ع1","ع2"],"rows":[["..",".."]]}  ← جدول
ملاحظة: الرسوم التوضيحية تُضاف تلقائيًّا حسب الدرس (لا تكتبها).

------------------------------------------------------------
كيف تعدّل أوراق العمل؟  (data/quizzes.json)
------------------------------------------------------------
الملف كائن، مفتاحه رقم الدرس، وقيمته مصفوفة أسئلة، كل سؤال نوعه "k":
  {"k":"sec","t":"عنوان القسم"}
  {"k":"mcq","q":"السؤال","code":false,"opts":["أ..","ب.."],"ans":1}   ← ans = رقم الخيار الصحيح (يبدأ 0)
  {"k":"tf","q":"العبارة","ans":true}
  {"k":"fill","q":"... ......... ...","ans":["إجابة مقبولة","بديل"]}
  {"k":"match","left":[{"t":"عنصر"}|{"c":"كود"}],"right":["أ. ..","ب. .."],"ans":[1,0,...]}  ← ans[i] = رقم عنصر العمود الأيسر
  {"k":"choose","q":"...","opts":["..",".."],"ans":1}
  {"k":"trace","q":"تتبّع الناتج","code":"..","out":"الناتج"}     ← تحقّق ذاتي
  {"k":"self","q":"..","model":"الإجابة النموذجية","code":"(اختياري)"}  ← تحقّق ذاتي

قواعد JSON: استخدم علامات تنصيص مزدوجة " ، وافصل العناصر بفواصل ، ولا تضع فاصلة بعد آخر عنصر.
انسخ نسخة احتياطية قبل التعديل. أي خطأ في الفواصل/الأقواس يمنع تحميل الملف.

ملاحظة: حفظ التقدّم والدرجات على جهاز الطالب (localStorage). لوحة متابعة المعلّم المركزية = المرحلة الثانية.

------------------------------------------------------------
محرّر المحتوى من المتصفّح:  editor.html
------------------------------------------------------------
افتح editor.html لتعديل الدروس وأوراق العمل عبر نماذج (بلا لمس أي كود):
  • إن شغّلت الموقع عبر خادم: يُحمّل المحتوى تلقائيًّا من data/.
  • أو اضغط «فتح ملفات JSON» واختر lessons.json و quizzes.json من القرص (يعمل حتى بلا خادم).
  • أو «فتح مجلد data» (في كروم/إيدج) لتفعيل «الحفظ المباشر» في الملفات.
التعديل: أضِف/احذف/رتّب العناصر، عدّل الحقول، ثم اضغط «حفظ / تنزيل».
  - «حفظ مباشر» يكتب في ملفات data/ (عند فتح المجلد بكروم/إيدج).
  - وإلا يُنزّل lessons.json و quizzes.json لتستبدلهما يدويًّا في مجلد data/.
زر «معاينة الدرس» يعرض شكل الدرس كما سيظهر للطالب.
انسخ نسخة احتياطية من مجلد data قبل التعديل.
